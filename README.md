# pairwise-chromatic-aberration

广角镜头快速摇过霓虹招牌时，画面边缘红蓝分开，停下来彩边还挂在灯牌上：色差按屏幕 UV 固定半径采样，没有跟焦距、光圈和畸变模型联动；畸变矫正和色差采样顺序反了，边缘被二次拉伸；超广角像素被拉出屏幕，越界采样没有 clamp 到边缘；HDR 亮度参与偏移量，亮部边缘出现彩色光晕；UI、字幕和准星一起被后处理，文字发虚；动态分辨率切换后半径按像素写死，不同画质下强度不一致；时域累积把色差当运动，静止画面仍有彩边；只采 R/B 通道，绿色边缘缺失；参数动画在帧末统一更新，快速切镜时跳变；移动端半精度计算，偏移量在亮部溢出；多相机分屏共用一套色差参数，右屏边缘更强；色差在 sRGB 空间做，线性空间下颜色偏移方向错；后处理资源在相机切换时没有重置历史。postfx/chromatic_aberration.py 是核心，tests/test_chromatic_aberration.py 15个红。要修的是：焦距联动；顺序校正；边界 clamp；亮度分离；UI 排除；分辨率归一；时域分离；三通道采样；逐帧参数；高精度计算；多相机隔离；色彩空间；历史重置。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
